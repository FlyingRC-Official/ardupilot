# FlyingRC H7Wlite V2

The FlyingRC H7Wlite V2 is an STM32H743 fixed-wing flight controller based on the Matek H743-WING pin layout.

Primary onboard sensors are two BMI270 IMUs, an SPA06-003 barometer, and a QMC5883P compass. The target also retains runtime probing for the earlier ICM42688P/ICM42605 IMU population.

The board provides twelve PWM outputs, analog OSD, microSD logging, seven UARTs plus USB, two I2C buses, one CAN bus, analog airspeed and RSSI inputs, and two battery-monitor inputs.
